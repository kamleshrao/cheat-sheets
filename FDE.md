## FDE Expreience Day (19-Sep-2026)

### Laptop Prerequisites 
For this session/training, the OS must be Windows only. The other OS (Mac, Ubuntu) is not supported.

- Node.js (v24.0.0 or later)
- npm (v11.0.0 or later)
- npx (v11.0.0 or later)
- Git CLI (v2.30.0 or later)
- GitHub CLI (v2.0.0 or later)
- Visual Studio Code (v1.80.0 or later)
- Azure CLI (v2.50.0 or later)
- OpenCode CLI (v1.17.13 or later)
- .NET SDK (v10.0.100 or later)
- sqlite3 CLI (v3.40.0 or later)
